# 🧠 Machine Learning Projects  

This folder contains a collection of machine learning and deep learning projects I have worked on, organized by **task type**. Each subfolder corresponds to a specific ML task and contains one or more projects applying different neural network architectures.  

---

## 📂 Project Structure  

### 🔹 Binary Classification  
- **Handwriting Recognition**  
  - Models: Convolutional Neural Network (CNN), ResNet  
  - Task: Classifying handwritten digits/characters.  

- **Diabetes Prediction**  
  - Model: Artificial Neural Network (ANN)  
  - Task: Predicting diabetes diagnosis based on patient medical data.  

- **Pulse Wave Discrimination** *(Final Project – ML/DL Course)*  
  - Model: Convolutional Neural Network (CNN)  
  - Task: Discriminating pulse wave signals using deep learning.  

---

### 🔹 Regression  
- **Boston Housing Prices**  
  - Task: Predicting house prices based on various features.  

- **Temperature Time Series Forecasting**  
  - Model: Recurrent Neural Network (RNN)  
  - Task: Forecasting future temperature values from past data.  

- **X-ray Absorption Spectra (XAS) Prediction**  
  - Model: Graph Neural Network (GNN)  
  - Task: Predicting XAS spectra using graph-based representations.  

---

### 🔹 Clustering  
- **Iris Flower Differentiation**  
  - Task: Clustering iris flowers into species based on feature similarities.  

---

### 🔹 NLP (Natural Language Processing)  
- **Text Review Classification** *(In Progress)*  
  - Task: Classifying text reviews into categories.  

---

## 🚀 Highlights
